# Tank OC Cloud

**A personal AI assistant for World of Warcraft: Forever.**

Tank OC Cloud connects a ChatGPT assistant to a cloud-hosted character service so players can retrieve and discuss character information, equipment, and statistics without keeping a personal computer running.

## Project

Tank OC Cloud is a personal project focused on the World of Warcraft: Forever version. Its goal is to bring character data and useful game-reference information into one conversational assistant.

Planned and developing capabilities include:

- Character profile, equipment, and statistics retrieval
- Item and equipment lookups
- Spell, quest, NPC, vendor, and dungeon reference
- Item source and drop information, where supported by the data provider

Features are subject to API availability and development.

## Data sources and attribution

We intend to use **[ForeverDB](https://foreverdb.net/)** as a game-data reference source, subject to API access approval and its terms. ForeverDB will be credited wherever its data is presented in the assistant.

This project is independent and is not affiliated with or endorsed by Blizzard Entertainment or the operators of World of Warcraft: Forever.

## Privacy and security

The application is designed to keep API credentials on the server side. Secrets, access tokens, and private character-service implementation code are not published in this repository.

## Status

This project is under active development. The public repository contains project information only; implementation code is maintained separately in a private repository.
